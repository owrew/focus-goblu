FOCUS GOBLIN 0.4 — LOCAL WINDOWS APPLICATION

Source project on this computer:
C:\Users\awais\OneDrive\Downloads\Computer vision program\focus-goblin

Installed-source launch: double-click Launch Focus Goblin.cmd.
Portable build: open FocusGoblin-v0.4.exe in the Windows folder build.
Installer: FocusGoblin-Setup-0.4.0.exe (per-user installation; no admin required).

The transparent desktop goblin pet appears with the camera OFF.
Drag to move; right-click for controls. It remains visible when the dashboard is minimized.

Try camera-free demo first, then Stop.
For real monitoring: Start camera, then Calibrate while looking at the screen for 5 seconds.

Phone detection is enabled automatically using the bundled YOLOX ONNX model.
Open Phone Check 2.0 on Today. Capture the front, back and angled views separately.
Review the per-view results, then apply the suggested threshold if useful.
Settings > Lighting & phone has Balanced/Eco/Custom detector options and auto-light controls.
If source model files are absent, run download-phone-model.ps1 once.

Pause closes capture; Resume reopens it. Stop saves and hides the pet.
Ctrl+Alt+P pauses/resumes from other apps (configurable in Settings).
Escape stops monitoring when the dashboard has keyboard focus.
Show pet brings the pet back without starting the camera.

All camera processing is local. No raw video is stored.
Session data: %LOCALAPPDATA%\FocusGoblin\focus.sqlite3

Preview reaction shows the pet and separate click-through screen-edge fire.
Settings includes name/color, cursor-follow, custom PCM WAV, personality, startup,
screen-fire placement, blur, background motion and animation rate.
Focus desk: enter session name/duration; type a task and press Enter to start.
False alarm logs feedback and silences reactions for 30 seconds.
Session archive: compare 7, 30 or 90 days with the preceding period and export an HTML report.
Sleep the goblin mutes reactions for three minutes while tracking continues.
Set the reaction delay to 2-300 seconds in Settings > Camera & rules.

LIMIT: approximate gaze; previous version camera test achieved about 3.0 observations/sec,
not the 12 FPS target. Real-user tracking, calibration and phone accuracy need your test.
